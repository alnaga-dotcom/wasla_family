# Wasla Landing v3 — Premium Experience

Includes the complete v2 improvements plus premium appearance upgrades, trust ribbon, Wasla Promise, animated matching journey, suitability checklist, smart footer, ambient brand motion, scroll progress, unified card behavior, and reduced-motion accessibility.

Connected to the backend for real numbers and plans:
- `/api/public/stats` — active members, verified members, matches, messages (excludes suspended/demo accounts).
- `/api/public/plans` — public pricing.

Run locally:
```bash
npm run serve
# http://127.0.0.1:8080
```

Smoke test:
```bash
npm test
# or: node scripts/landing-smoke.mjs
```
